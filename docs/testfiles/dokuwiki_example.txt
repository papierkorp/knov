===== Text formatting =====

**bold**, //italic//, __underline__, ''monospace'' and <del>deleted</del> text can be combined: **__//''all at once''//__**.

  DokuWiki also supports: **fetten**, //kursiven//, __unterstrichenen__ und ''dicktengleichen'' Text.

Superscript and subscript: 19^th^ and H<sub>2</sub>O.

__Escaped syntax__ => should render as ''_italic_'' instead of turning into italic in markdown.

===== Links =====

[[wiki:start]] is an internal wiki link. See also [[intro#installation]] for an anchor link, or [[intro:installation:steps|the installation guide]] for a labelled one.

  * Internal Link1: [[wiki:start]]
  * Internal Link2: [[intro:section:subsection|example]]
  * Internal Link3: [[#link_anchor]]
  * Internal Link4: [[#link_anchor|jump here]]
  * External Link1: [[www.example.com]]
  * External Link2: [[https://example.com]]
  * External Link3: [[example|www.example.com]]
  * External Link4: [[example|https://example.com]]

[[wiki:DokuWiki]] can highlight sourcecode using the [[http://qbnz.com/highlighter/|GeSHi]] Generic Syntax Highlighter, e.g. ''<nowiki><code java></nowiki>'' or ''<nowiki><file java></nowiki>''.

===== Escaping =====

Escape 1: ''smb:%%//%%server/share''
Escape 2: command1 %%||%% command2
Escape 3: %%//%% not a comment
Escape 4: %%----%% (not a horizontal rule)

===== Notes =====

**Problem**

We want to avoid storing plaintext secrets in a repository (e.g. ''config.yml'').

**Possible approaches**

1. External secret manager
  * process
    * install a secret operator in the cluster
    * store secrets in the external manager
    * reference the secret from the repository
  * pros
    * central rotation of secrets
    * no plaintext secret in the repository
  * cons
    * additional setup effort
    * requires an extra external tool
2. Encrypted secret in git
  * process
    * install a cluster secret tool
    * commit an encrypted secret to the repository
    * the tool decrypts it on the fly
  * pros
    * changes are tracked in git
  * cons
    * less flexible
    * depends on a certificate that can expire
