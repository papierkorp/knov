# KNOV - Knowledge Management System

KNOV (Knowledge Vault) is a local-first open source knowledge management system that runs as a single self-contained binary. No cloud, no account, no dependencies.

Your content is plain markdown files on disk, versioned with git. Metadata, search index, chat and config live in SQLite alongside them. Connect a git remote to sync between machines or share with others.

## Quickstart

1. Get the binary (or `.exe`) - or build it yourself with `make prod`
2. Copy `.env.example` to `.env` and adjust the values
3. Run the binary - it creates all needed folders and a git repository automatically
4. Open `http://localhost:1324` (or your configured port)
5. Check `/system/environment` any time for every recognized `KNOV_*` variable with its description, default and current value

**Docker:** copy `.env.example` to `tools/docker_deployment/.env`, then run `docker compose up` from that folder.

To update: stop knov, replace the binary, start again - your data and settings are untouched.
To move machines: copy the binary and your data folder.
